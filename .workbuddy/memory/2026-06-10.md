## 2026-06-10 — Docker 化 blog-agent

### 完成
- **Dockerfile**: 多阶段构建（golang:1.24-alpine → alpine:3.21），CGO_ENABLED=0，ldflags="-s -w" -trimpath，非 root 用户运行，健康检查
- **docker-compose.yml**: Redis 7-alpine + blog-agent，数据卷挂载 blogs_txt & logs，健康检查依赖
- **.dockerignore**: 排除非 blog-agent 的 cmd/、文档、Git、临时文件，大幅减小构建上下文

### 架构要点
- monorepo 无根 go.mod，每个 cmd/* 独立模块
- blog-agent 通过 replace 指令引用 ./pkgs/* 和 ../common/*
- 模板/静态资源运行时从文件系统加载（非 embed），必须 COPY 到镜像
- blogs_txt 为运行时数据，通过 volume 挂载
- Redis 为唯一外部依赖（端口 6666）

### 使用注意
- Docker 环境中 sys_conf.md 的 redis_host 须改为 `redis`（容器服务名）
